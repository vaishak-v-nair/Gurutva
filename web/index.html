The same code, ten thousand billion billion times further away

The engine above was written for gravity stations in a Utah desert. It was then run, without a single line changed, on the weak-lensing shear of a dark-matter halo.

It works because both are the same problem: mass inferred from the field it makes. Prisms→gravity and mass-sheet→shear share an operator signature, so the engine does not care what the mass is made of, or whether it is a kilometre down or 1022 km away. The drilling interval and the exclusion limit are one number with two names.

An exclusion limit is what a physicist publishes when a search comes up empty. A posterior sigma is what a mining company needs before drilling. They are the same array, from the same function.

And then the product caught itself, so we built a fifth gate

All four core gates passed — and the map still missed a truth we happened to know. Only 38% of pixels had the right answer inside their 95% interval, worst miss 4.9 sigma.

None of the four could see it. Licensing asks whether the data is plausible, never the truth. Calibration draws its test truths from the prior, so it is blind by construction. Two runs agree on the same wrong answer, and a smoothed field still reproduces the shear. So gate 5 now exists: does the interval contain a known right answer? It runs whenever a truth is available, and when none is, the verdict says so out loud instead of letting silence read as success.

Gate 5 fails here, so this map is not claimed. We widened the prior class first, and measured that it does not rescue it: the aperture bias is shrinkage and widening helps, but the peak bias is the lensing operator smoothing a cusp it cannot resolve, and no prior undoes that. A prior wide enough to fix the aperture also degrades the exclusion limit 2.2×. So the limit stays, the map does not, and the CO2 report above now carries gate 5 too — where it passes at 0.3σ.

Four questions, asked in order

01 / LICENSING

Could my assumptions ever have produced this measurement?

If not, nothing further is allowed to be claimed.

02 / CALIBRATION

When I say 95% sure, am I right 95% of the time?

Checked by simulation, against the sampling floor.

03 / STABILITY

Run it twice from scratch. Same answer?

At the real observation, not only in simulation.

04 / ADEQUACY

Can the answer reproduce the data it came from?

The gate that failed at the top of this page.

The first three ask whether the model is self-consistent. All three passed on a model that was wrong. Only the fourth asks whether it is right.

What it refuses to tell you

“Less than 106 Mt of CO2 escaped the storage complex.”
Computed, then refused. That bound is 1065% of everything injected, and it is set by the prior rather than the survey. An exclusion limit only means something for a body you can name.
“There is no leak outside the complex.”
Only above 72% saturation. A 400 m accumulation emptier than that cannot be ruled out by this survey at all, so no containment claim covers it.
“Rock density here varies by 0.021 g/cc.”
What the standard tuned regularizer implies if you read it as a statement about rock. Licensing failed it at the 100th percentile: that prior could not have produced the anomaly that was measured.

Every other tool in this business sells confidence. This one is built to withhold it.
